# 消防站室内布置与核对

本版按 station.html 使用的实建平面组织 12 间房与员工通道。房间图覆盖真实墙段、门洞、窗、北向、米制网格、家具朝向和台面物资。每张图列出相应参考资料，在线资料用于空间用途和陈设关系，尺寸取自本关与 GLB。[逐房图集](../../public/assets/station-rooms/index.html) · [关卡实景总览](../../public/assets/station-rooms/interiors.jpg)

## 安装依据

| 项目约定 | 在本关的做法 |
|---|---|
| ART-SNAP-01 分类与安装 | 地面家具以 site 楼板支撑；工具、餐具和文件指定台面宿主；壁件绑定覆盖安装位置的实际墙段，按完成面法向定位。卷叶随 gate，手链及框体随建筑。 |
| ART-SNAP-02 交接字段 | station-rooms.json 记录资产、房间、稳定 ID、宿主、米制宽高深、朝向和安装位置；saved.json 记录已保存的关卡位置。房间图中的桌面附属物列在家具下方。 |
| ART-SNAP-03 加载 | 灰盒与美术共用放置记录。已有家具的正面校正角在美术实例上应用。可见网格在楼板完成面上方补偿 0.012 m。 |
| ART-SNAP-04 复查 | 放置校验重读保存记录；房间校验比较有向占地、上下限、台面宿主及墙厚。检查地面家具与其他件超过 0.01 m 的无关穿插。 |
| ART-INT-01 交互物 | 值班台对应 IN-01 / IN-03 / IN-08，试泵台对应 IN-01 / IN-04，推车对应 MV-02 / CB-01，卷门对应 DR-04 / DR-08。 |
| 功能尺寸 | 资产库卷门参考净宽 4.80 m。本版实建车厅洞口净宽 12.00 m，净高 4.50 m，订单状态半开净高 1.25 m。复用卷叶和底梁几何，固定门框接原建筑洞口。 |

## 复核方法

- 用 `node tools/station-kit/room-audit.mjs` 检查房间内无关穿插、附属物相对宿主的四角占地，以及 0.25 m 采样网格上的 1.20 m 净宽路线。目标含 13 个空间、手链操作位和北门内侧。
- 用 `node tools/station-placement-audit.mjs` 检查 271 个已保存构件的宿主和安装点。用 `node tools/station-kit/room-review.mjs` 从实际美术场景加载 150 项陈设并重拍 13 张图。
- 军用站标准用于维修和洗消的房间功能参考；市政平面和建筑师照片用于柜架、餐厨、休闲与值班家具的布置。[USACE 标准设计](https://mrsi.erdc.dren.mil/content/cos/hnc/fs/Library/Standard%20Designs/Standard_Design_Fire_Station__Mar2021_.pdf) · [Falmouth 改造平面](https://www.falmouthme.org/DocumentCenter/View/2006/Updated-Central-Fire-Station-Renovation-Plans-12826?bidId=) · [CCD 室内照片](https://ccdarchitects.com/portfolio-item/fire-station-20/) · [Amarillo 5 号站](https://www.sims-architects.com/city-of-amarillo-fire-station-5)
- 从 `station.html?play=1` 实测加载 150 项。角色由南门外步行至前厅 X 17.41、Z 5.89；N 返回连续步行路径，E 核对工单后目标切换为去维修间试泵，R 返回楼板命中距离 7.9 m。此段浏览器测试无页面脚本错误。13 个空间另以正式美术场景逐房实机截图。该轮实测覆盖入口与接单，重货全程和真人盲测仍待验证。
