## 当前阶段：P0 · 技术与视觉预研（待审）

### 已完成
- **P0.1 技术验证**：Vite 8 + Three.js r187（WebGPURenderer + TSL）
  - 后处理链：法线/速度预渲染 → GTAO（半分辨率）→ TRAA → 泛光 → AgX 色调映射 → 自定义调色（对比/饱和/冷暖分离/暗角/颗粒）
  - 级联阴影（CSM，3 级），阴天 HDRI 环境光，距离雾 + 贴地雾
  - 实例化渲染（InstancedMesh），调试面板内置植被压测（+1/3/6 万实例）
  - 支持 `?webgl` 强制 WebGL2 回退
- **P0.2 视觉目标**：`docs/视觉目标.md`（初稿，等你补充俯视参考图）
- **P0.3 氛围样板间**：60m×60m 十字路口街区
  - 5 栋程序化拼装的废弃楼（Poly Haven 模块化立面套件，随机窗型、碎玻璃、封窗）
  - TSL 废土化材质：世界空间苔藓覆盖、墙面植物蔓延、墙根污渍、雨痕、潮湿变暗、地面积水坑
  - 残骸车 8 辆、混凝土路障、铁丝网营地围栏、杂物、5 类植被约 1,800 株

### 运行
```
npm install
npm run fetch-assets   # 首次：从 Poly Haven 下载约 100MB CC0 资产到 public/assets/
npm run dev            # http://localhost:5173
```
操作：右键拖动旋转、滚轮缩放、WASD 平移、C 切换俯视/近景、P 截图。右上角「调试面板」可调全部氛围参数并导出。

### 性能（RTX 5080，1080p 级视口）
- 俯视：GPU 约 4–9 ms，绘制调用约 420，三角面约 30M（含阴影级联重复绘制）
- 已知：植被模型是 Poly Haven 高模（单株最高 2.7 万面），**P4 必须做 LOD / 低模替换**

### 已知问题 / 下一步
1. 植被是散点放置，还没有「墙面藤蔓」几何体（参考图 1 的爬藤效果目前只靠材质模拟）
2. 屋顶是平板，没有坍塌、积水、杂物
3. 没有室内（参考图 2/3 的手电+黑暗室内效果未验证）——属于 P3.6
4. 车辆只有一种（盖布轿车），需要更多残骸车型
5. 阴影级联在近景时边缘偏软
