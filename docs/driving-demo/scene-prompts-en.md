# 08 × 10 Seattle District | Scene Concept Art Prompts

Coordinates are in meters, measured from the northwest corner. X increases eastward and Y southward. Use coordinates to locate the reference crop. Keep coordinate numbers off the artwork. When image conditioning is available, attach the corresponding crop from layout.png and give structural guidance more weight than style. For text-only generation, start with scene 01 and use it as the geographic reference for subsequent exterior shots. Site positions follow the level layout. Local architecture and props are art proposals for the blockout. Each positive prompt includes the shared visual direction so it can be copied independently.
