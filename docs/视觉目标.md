**结论**
- 室外：**低饱和（0.15–0.28）**、**暗部偏青绿**、整体中低亮度；高光只来自天空和湿面反射。
- 室内：**极暗**（中位亮度 20–40），唯一的光源是手电或窗口，暖色只出现在人造光源处。
- 绿色是**灰掉的绿**（`#5b644f` 一类），不是鲜艳的草绿。

## 3. 俯视角下的构图原则

参考图都是第三人称近景，俯视镜头看不到天空和建筑立面细节，因此俯视下的氛围要靠：
1. **地面信息量**：积水反光、苔藓斑块、杂物、植被——俯视时地面占画面 60%+
2. **屋顶**：废弃 20 年的屋顶应该长满苔藓、积水、有坍塌洞口（P3 待做）
3. **阴影与 AO**：建筑之间的暗巷对比度
4. **雾**：只用于压远处的边缘，俯视主体区域内应保持清晰

**需要你补充**：3–5 张「俯视角下也该是这个感觉」的参考（其他游戏的俯视截图、废墟航拍照片均可）。
