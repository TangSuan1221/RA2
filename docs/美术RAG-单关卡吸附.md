# 美术 RAG · 单关卡放置与吸附关系

适用范围：所有新建、修改、验收和合并的单个关卡，包括灰盒、替换后的正式美术资产与验收台。检索词：关卡吸附、门窗漏缝、家具离格、道具悬空、楼层标高、父子安装、灰模验收。

## ART-SNAP-01｜选关系，再放物件

| 对象 | 宿主和依据 | 放置方式与验收 |
|---|---|---|
| 楼板、墙段、踏步、坡道 | 楼层基准、墙段轴线、楼梯起终点 | structural。通过兼容 socket 决定标高和朝向；以同一剖面生成踏面、承重面和通行面。 |
| 门框、门扇、窗、雨棚 | 开口两侧、过梁、门槛、外墙面 | structural。门洞与扇共用开口尺寸来源。逐边比较有效封闭范围；有意门缝必须有定量设计值。对齐中心不能代替尺寸核验。 |
| 护栏、梯子、横杆 | 楼板边、端柱、梯梁 | 先落端柱，再连接横杆。每根横杆有落点，每个开口对应真实通行口。 |
| 链条、横闩、标牌、交互点 | 门框、门扇、实体墙或车辆安装面 | semantic。给出安装面、法向和局部位置；移动部件上的把手随部件，固定在墙上的拉链留在框上。 |
| 家具、车辆、箱、桌面物资 | 所属楼层、台面、车辆托架 | prop。XZ、yaw 默认自由；按旋转占地四角及中心取支撑面最高点。同一 XZ 有多层时指明支撑宿主。 |
| 贴花、标签、小附件 | 所贴表面或 prefab 局部基准 | decor。表面贴附或固定局部偏移。子部件随父件；父级记录覆盖整个复合件。 |

## ART-SNAP-02｜资产交接字段

每个场景放置件提供稳定 ID、profile、米制占地、底面轴心、所属宿主/支撑面、安装点或接触依据。Y 向上，XZ 为平面，yaw 使用度。复合资产内部的踏步细分、贴花和操作标识可以由父件局部尺寸生成。玩家、特效和运行时投掷轨迹不属于静态放置清单。

## ART-SNAP-03｜编辑、保存、运行

结构件缺 socket、贴地件缺支撑、占地越界均阻止提交。净空、重叠、坡度、通行分档和开口尺寸报警并保留 transform；修正几何和再次核验后才能宣称消除了问题。编辑时求解；保存的 transform 是试玩和发布的位置真值。平移可拆资产时复核依附物及碰撞，固定复合件整体变换。

## ART-SNAP-04｜每关验收

1. 由稳定 ID 对照建模清单、预制件内部清单和保存记录，列出遗漏或重复。
2. 分层查看支撑面，抽测门槛、墙角、栏杆端部、梯段接口和台面物资。门关闭时测遮挡；开门后测通行。
3. 保存后重载，比较 transform；检查碰撞、交互点及移动表面是否与视觉一致。
4. 记录宿主、警告及处理结果，单关验收后再合入大地图。

消防局实例见 src/world/placements/station-layout.js、station-walls.js、saved.json；策略实现见 src/editor/snap/。新关卡沿用上述 ID 和规则分类，另建自己的平面、剖面、开口和宿主数据。

## 关联检索 · 交互物尺寸

设计门窗、攀爬点、设施、容器、拾取物或触发器时，按交互物 ID 查询尺寸等级、参考范围与测量部位，再用本文确定宿主和安装关系。[交互物清单与尺寸规范](./美术RAG-交互物清单与尺寸规范.md)
## ART-BOX｜可玩灰盒与尺度验收

- **ART-BOX-01 角色走位。** 从正常试玩入口生成可见角色，接入透视相机、步行、奔跑、碰撞和地面支撑。用项目角色在前厅、门洞、走廊、掩体和高低差之间实际往返；记录角色胶囊、运动状态和卡点。
- **ART-BOX-02 米制网格。** 结构使用中性灰（推荐 #8c8c8c），各表面按世界米制投影，1 m 主格、0.5 m 次格。检查水平面、竖墙、转角、旋转墙段和踏步。以角色作参照核对高度、双人错身宽度与高差。
- **ART-BOX-03 两类灰模。** 墙、楼板和固定通行楼梯共用结构网格；掩体、可破坏箱和可利用的高低台使用更深的灰网格或轮廓边。提示色限于交互和调试标记。视觉体积须与碰撞及遮挡一致。
- **ART-BOX-04 射线及寻路。** Three.js 用 Raycaster 检查相机视线和角色发出的命中线，显示首个命中或无遮挡结果。网格或导航网格采用与角色一致的净空、标高和动态障碍。分别验证可达、受阻、门状态变化、箱体破坏后重新求路，记录构建版本；俯视图用于辅助观察。
